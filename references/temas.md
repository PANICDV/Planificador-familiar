# Temas sugeridos según el grupo

Presenta solo los que apliquen y deja que la familia elija, quite o añada. Cada tema elegido
va a una sección (ver `secciones-base.md`).

## Para todos los grupos
| Tema | Qué incluye | Tipo de sesión |
|---|---|---|
| 🏡 Hogar | Limpieza, cocina, compras, plantas, mantenimiento | Bloques cortos (20–60 min), repartidos |
| 🔄 Espacios flexibles | Descansos, imprevistos, lo que no se cumplió | Siempre al menos uno al día |
| 💞 Tiempo sin agenda | Pareja o familia, sin objetivo productivo | Se marca como "libre", no como tarea |
| 🔔 Recordatorios | Riego, limpiezas cada N días, pagos, mantenimientos, trámites | Calendario aparte, no se regenera |
| 🏃 Salud y movimiento | Ejercicio, caminatas, mascotas, citas médicas | Bloques personales |

## Para adultos (pareja u hogar de adultos)
| Tema | Ejemplos |
|---|---|
| 🧠 Aprender y crear juntos | Ciberseguridad, IA, programación con IA, idiomas, cursos |
| 🎬 Contenido y monetización | Publicar, automatizar, emprendimiento, ventas |
| 🖥️ Tecnología del hogar | NAS, respaldos, red, domótica, aprovechar recursos que ya tienen |
| 💼 Trabajo / estudios | Horario fijo, tesis, búsqueda laboral |
| 💳 Finanzas del hogar | Presupuesto, pagos, revisión mensual (como recordatorio) |
| 🧾 Trámites | Documentos, bancos, colegio: fecha incierta → opción A / B |

## Para hogares con hijos/as
| Tema | Ejemplos |
|---|---|
| 👧👦 Rutina de cada hijo/a | Colegio, tareas, deporte, idiomas, tiempo de pantallas |
| 📚 Aprender con ellos | Lectura, idiomas, experimentos, programación para niños |
| 🧸 Tiempo en familia | Paseos, juegos, películas, comidas |
| 🧹 Tareas del hogar por edad | Recoger, poner la mesa, cuidar plantas o mascotas |
| 🚌 Logística | Quién recoge, quién lleva, quién cocina cada día |

## Para hogares de 3+ adultos (o roommates)
| Tema | Ejemplos |
|---|---|
| 🏡 Turnos del hogar | Rotación semanal de limpieza y cocina |
| 🧾 Gastos compartidos | Recordatorio mensual de cuentas |
| 🗓️ Espacios comunes | Reserva de sala, visitas |

## Cómo sugerir
1. Elige 4–6 temas según la composición que dijo la persona.
2. Pregunta cuáles son prioridad ahora y cuáles pueden esperar.
3. Recuerda que **no todo debe ser productivo**: siempre incluir tiempo sin agenda.
4. Si un tema es de una sola persona, va en su calendario personal, no como sección compartida.
